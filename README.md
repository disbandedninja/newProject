# Toxic Social Interaction Incident Documentation (Electron)

Desktop app to document and track toxic social interaction incidents.

## What this includes
- Desktop UI built with Electron.
- Incident intake form with required fields.
- Local JSON persistence in the app's user data directory.
- Incident list and filters (severity/status/category).

## Quick start
```bash
npm install
npm start
```

## Run tests
```bash
npm test
```

## Data storage
Incidents are stored locally as `incidents.json` in Electron's `userData` directory.
